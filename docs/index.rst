Flask PySAML2
=============

:release: |release|

Flask PySAML2 is a Flask module adding SAML Service Provider (SP)
support to Flask. PySAML2 is an incredibly robust SAML 2.0 implementation
for Python. This project currently provides support for client-side Single
Sign-On (SSO) and Single Log-Out (SLO) via SAML 2.0.

Future plans are to add Identity Provider (IDP) SSO support which will
allow for using this module to support SAML 2.0 based authentication
completely.
